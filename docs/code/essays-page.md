# `app/essays/page.tsx`

## Σκοπός

Το `app/essays/page.tsx` αποτελεί την κεντρική σελίδα της ενότητας Essays του Portfolio.

Η διαδρομή της σελίδας είναι `/essays`.

## Υλοποίηση

Δημιούργησα το React component `EssaysPage()`, το οποίο επιστρέφει ένα `Container` του Chakra UI με ένα `Heading`.

- `Container`: Περιορίζει το μέγιστο πλάτος του περιεχομένου μέσω του `maxW="3xl"`.
- `Heading`: Εμφανίζει τον τίτλο "Essays".
- `as="h1"`: Ορίζει τον κύριο τίτλο της σελίδας.
- `fontSize`: Προσαρμόζει το μέγεθος του τίτλου ανάλογα με το breakpoint.
- `letterSpacing="tight"`: Ρυθμίζει την απόσταση μεταξύ των χαρακτήρων.

## Έλεγχος

- Η διαδρομή `/Essays` εμφανίστηκε στον browser.
- Ο έλεγχος ESLint ολοκληρώθηκε χωρίς αναφερόμενα σφάλματα.

## Επόμενα βήματα

Η κεντρική σελίδα θα περιλαμβάνει δύο ξεχωριστές καρτέλες:

- Learning: `/essays/Learning`
- Philosophy: `/essays/philosophy`

Κάθε κατηγορία θα οδηγεί στη δική της σελίδα με τα αντίστοιχα δοκίμια.
