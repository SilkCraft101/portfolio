# `.gitignore`

## Ρόλος του αρχείου

Το αρχείο ορίζει ποια μη παρακολουθούμενα αρχεία και φακέλους αγνοεί το Git. Δεν διαγράφει αρχεία από τον υπολογιστή και δεν σταματά την παρακολούθηση αρχείων που έχουν ήδη προστεθεί στο Git.

## Σύνταξη των patterns

Οι γραμμές που ξεκινούν με `#` είναι σχόλια. Το `*` αντιστοιχεί σε χαρακτήρες ονόματος, χωρίς να περνά από διαχωριστικά φακέλων. Το αρχικό `/` περιορίζει ένα pattern στη θέση του συγκεκριμένου gitignore, εδώ στη ρίζα του project. Το τελικό `/` περιορίζει το pattern σε φακέλους.

Το `!` δηλώνει εξαίρεση από προηγούμενο κανόνα αγνόησης. Δεν επιτρέπει από μόνο του την επανένταξη περιεχομένου αν ολόκληρος ο γονικός φάκελος παραμένει αποκλεισμένος.

## Dependencies

Το `/node_modules` αφήνει εκτός Git τα εγκατεστημένα πακέτα. Οι δηλώσεις και οι συγκεκριμένες επιλύσεις τους παραμένουν στα package.json και package-lock.json.

Τα `/.pnp`, `.pnp.*` και `.yarn/*` αφορούν εναλλακτικές διατάξεις dependencies του Yarn. Οι εξαιρέσεις για patches, plugins, releases και versions επιτρέπουν να συμπεριληφθούν οι συγκεκριμένοι υποφάκελοι. Η παρουσία των patterns δεν σημαίνει ότι το project χρησιμοποιεί Yarn.

## Παραγόμενα αρχεία

Οι φάκελοι `.next`, `out` και `build` αφορούν έξοδο εργαλείων ανάπτυξης ή build. Το `coverage` αφορά αναφορές κάλυψης tests· η εξαίρεσή του δεν σημαίνει ότι υπάρχουν ήδη tests.

Το `*.tsbuildinfo` καλύπτει αρχεία πληροφορίας incremental ελέγχων TypeScript. Το `next-env.d.ts` εξαιρείται επειδή δημιουργείται από το Next.js.

## Τοπικά αρχεία και logs

Το `.DS_Store` αφορά μεταδεδομένα του macOS. Τα patterns για npm, Yarn και pnpm αφήνουν εκτός τα αντίστοιχα debug και error logs. Το `.vercel` αφορά τοπικά δεδομένα του εργαλείου Vercel και δεν αποδεικνύει ότι έχει γίνει deployment.

Το `*.pem` αγνοεί αρχεία με τη συγκεκριμένη κατάληξη, που μπορεί να περιλαμβάνουν πιστοποιητικά ή κλειδιά. Το `.env*` καλύπτει ονόματα που ξεκινούν με `.env`, μαζί με τυχόν `.env.example` όσο δεν υπάρχει πρόσθετη εξαίρεση.

## Τρέχον checkpoint

Το αρχείο κρατά τα patterns της αρχικής δομής. Αποτελεί κανόνα επιλογής για το Git, όχι μηχανισμό ασφάλειας που εμποδίζει κάθε πιθανή προσθήκη ευαίσθητου αρχείου.
