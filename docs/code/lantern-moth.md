# Lantern Moth

## Σκοπός

Τρισδιάστατο μοντέλο για τη μελλοντική δημιουργία διαδραστικού στοιχείου στην αρχική σελίδα του Portfolio.

## Προέλευση και άδεια χρήσης

- Δημιουργός: yair.
- Πηγή: [Blockbench Workshop](https://blockbenchworkshop.com/model/yair/lantern-moth).
- Αναφερόμενη άδεια: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

## Ρυθμίσεις εξαγωγής

Η εξαγωγή πραγματοποιήθηκε μέσω του Blockbench.

| Ρύθμιση                   | Τιμή         |
| ------------------------- | ------------ |
| Encoding                  | Binary (GLB) |
| Model Export Scale        | 16           |
| Embed Textures            | Enabled      |
| Export Groups as Armature | Disabled     |
| Export Animations         | Enabled      |
