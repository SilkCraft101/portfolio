# next-env.d.ts

## Σκοπός

Αυτόματα παραγόμενο αρχείο δηλώσεων τύπων που επιτρέπει στο TypeScript να αναγνωρίζει τους απαραίτητους τύπους του Next.js.

## Λειτουργία

Περιλαμβάνει αναφορές στους τύπους του Next.js, των εικόνων και των παραγόμενων διαδρομών της εφαρμογής.

## Τεχνικές αποφάσεις

- Δεν τροποποιείται χειροκίνητα.
- Εξαιρείται από το Git μέσω του `.gitignore`.
- Οι προσαρμοσμένες δηλώσεις τύπων τοποθετούνται σε ξεχωριστά αρχεία.
