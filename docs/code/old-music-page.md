# `app/music/old_music/page.tsx`

## Ρόλος του αρχείου

Το αρχείο ορίζει τη σελίδα `/music/old_music`, στην οποία παρουσιάζω τις παλαιότερες μουσικές μου δημιουργίες στο είδος Drill.

Η σελίδα αποτελεί μέρος της μουσικής ενότητας του Portfolio και είναι προσβάσιμη από την αντίστοιχη κάρτα της κεντρικής σελίδας `/music`.

Η συλλογή περιλαμβάνει 40 Drill beats, τα οποία έχουν δημοσιευτεί στο BandLab με τον τίτλο **Old Drill Beats**.

## Εισαγωγές και exports

Χρησιμοποιώ τα `Container`, `Heading` και `Text` από το Chakra UI.

Το `Link` εισάγεται από το `next/link` για την επιστροφή στην κεντρική μουσική σελίδα.

Το `Metadata` εισάγεται ως TypeScript type από το Next.js.

Η function `OldMusicPage` αποτελεί το default export και είναι το page component της διαδρομής `/music/old_music`.

## Metadata

Το αρχείο εξάγει ένα αντικείμενο `metadata` με τον τίτλο και τη σύντομη περιγραφή της σελίδας.

```tsx
export const metadata: Metadata = {
  title: "Drill Beats",
  description:
    "Μια συλλογή παλαιότερων Drill beats από τη μουσική μου διαδρομή.",
};
```

Τα metadata χρησιμοποιούνται από το Next.js για τη δημιουργία των αντίστοιχων HTML metadata της σελίδας.

Η περιγραφή δεν αναφέρει συγκεκριμένο έτος δημιουργίας των κομματιών, καθώς αυτό δεν έχει επιβεβαιωθεί.

## Δομή της σελίδας

Το κύριο περιεχόμενο βρίσκεται μέσα σε ένα HTML `main` element:

```tsx
<main id="main-content" lang="el">
```

Το `id="main-content"` επιτρέπει τη στόχευση του κύριου περιεχομένου από τον μηχανισμό πλοήγησης της εφαρμογής.

Το `lang="el"` δηλώνει ότι η κύρια γλώσσα του περιεχομένου είναι τα ελληνικά.

Το `Container` χρησιμοποιεί `maxW="3xl"`, διατηρώντας κοινό μέγιστο πλάτος με τις υπόλοιπες σελίδες του Portfolio.

Η δομή περιλαμβάνει:

1. Τον κύριο τίτλο της σελίδας.
2. Δύο παραγράφους προσωπικής παρουσίασης.
3. Έναν σύνδεσμο επιστροφής στην κεντρική μουσική ενότητα.

## Τίτλος της σελίδας

Ο τίτλος χρησιμοποιεί το `Heading` component του Chakra UI.

```tsx
<Heading
  as="h1"
  fontSize={{ base: "2xl", md: "3xl" }}
  letterSpacing="tight"
  mt={3}
>
  <span lang="en">Drill Beats</span>
</Heading>
```

Το `as="h1"` ορίζει τον κύριο τίτλο της σελίδας.

Το `fontSize` προσαρμόζει το μέγεθος της γραμματοσειράς ανάλογα με το breakpoint.

Το `letterSpacing="tight"` χρησιμοποιεί το αντίστοιχο typography token του Chakra UI.

Το `lang="en"` δηλώνει τη γλώσσα του αγγλικού τίτλου.

## Προσωπική παρουσίαση

Οι δύο παράγραφοι εξηγούν τη σχέση μου με τις παλαιότερες Drill δημιουργίες.

Η πρώτη παρουσιάζει τη συλλογή και τον ρόλο που είχε η μουσική ως μέσο έκφρασης σε μια δύσκολη προσωπική περίοδο.

Η δεύτερη εξηγεί γιατί επέλεξα να διατηρήσω αυτές τις δημιουργίες, παρότι η μουσική με την οποία ασχολούμαι σήμερα έχει διαφορετικό χαρακτήρα.

Κάθε παράγραφος χρησιμοποιεί ξεχωριστό `Text` component:

```tsx
<Text color="fg.muted" lineHeight="tall" mt={4}>
  ...
</Text>
```

Το `fg.muted` είναι semantic color token του Portfolio και προσαρμόζεται στο Light και Dark Mode.

Το `lineHeight="tall"` αυξάνει το διάστιχο για ευκολότερη ανάγνωση.

Το `mt={4}` προσθέτει κατακόρυφη απόσταση πριν από κάθε παράγραφο.

## Separator και BandLab Player

Κάτω από τον σύνδεσμο επιστροφής χρησιμοποιώ το `Separator` component του Chakra UI, ώστε να διαχωρίζεται οπτικά η προσωπική παρουσίαση από τη μουσική συλλογή.

```tsx
<Separator borderColor="border.subtle" my={6} w="full" />
```

- `borderColor="border.subtle"`: Χρησιμοποιεί ένα διακριτικό semantic color.
- `my={6}`: Προσθέτει κατακόρυφη απόσταση πάνω και κάτω από τον διαχωριστή.
- `w="full"`: Ορίζει πλάτος 100% του διαθέσιμου χώρου.

Στη συνέχεια χρησιμοποιώ ένα HTML `iframe` για την ενσωμάτωση του δημοσιευμένου BandLab album **Old Drill Beats**, το οποίο περιλαμβάνει 40 μουσικά κομμάτια.

```tsx
<iframe
  width="100%"
  height="500"
  src="https://www.bandlab.com/embed/collection/?id=3ff72f11-15e7-f111-91f2-70a8a56ceb96"
  title="BandLab player — Old Drill Beats"
></iframe>
```

### Πώς λειτουργεί

- `src`: Το πραγματικό embed URL του album στο BandLab.
- `width="100%"`: Προσαρμόζει το πλάτος του iframe στον διαθέσιμο χώρο του parent container.
- `height="500"`: Ορίζει σταθερό ύψος 500 CSS pixels.
- `title`: Περιγράφει τον player και το album για τους χρήστες screen readers.

Το `iframe` είναι εγγενές HTML element και δεν χρειάζεται ξεχωριστό React import.

### Σύνδεση με το Portfolio

Ο επισκέπτης μπορεί να ακούει τα **Old Drill Beats** απευθείας στη σελίδα `/music/old_music`.

Τα μουσικά αρχεία εξακολουθούν να φιλοξενούνται στο BandLab και δεν προστίθενται στο Git repository ή στο Vercel deployment.

Η αρχική σταθερή τιμή `width="700"` προκαλούσε οριζόντια υπερχείλιση σε μικρά παράθυρα.

Με την αλλαγή σε `width="100%"`, επιβεβαίωσα ότι ο player προσαρμόζεται σωστά σε desktop και μικρό πλάτος παραθύρου.

Επιβεβαίωσα επίσης ότι η αναπαραγωγή ήχου λειτουργεί κανονικά στον browser.

## Responsive Design

Η σελίδα χρησιμοποιεί responsive μέγεθος γραμματοσειράς στον κύριο τίτλο:

```tsx
fontSize={{ base: "2xl", md: "3xl" }}
```

Ο ενσωματωμένος BandLab player χρησιμοποιεί `width="100%"`, ώστε να προσαρμόζεται στον διαθέσιμο χώρο του `Container`.

Η αρχική τιμή `width="700"` προκαλούσε οριζόντια υπερχείλιση σε μικρά παράθυρα browser.

Μετά την αλλαγή σε `width="100%"`, επιβεβαίωσα ότι ο player εμφανίζεται σωστά τόσο σε desktop όσο και σε μικρό πλάτος παραθύρου, χωρίς horizontal overflow.

Το `height="500"` παραμένει σταθερό.

### Προσβασιμότητα του BandLab player

Το ενσωματωμένο `iframe` χρησιμοποιεί το attribute:

`title="BandLab player — Old Drill Beats"`

Το `title` περιγράφει το ενσωματωμένο περιεχόμενο, βοηθώντας τους χρήστες screen readers να αναγνωρίζουν ότι πρόκειται για τον μουσικό player του album **Old Drill Beats**.

Ο player φορτώνεται από το BandLab μέσα σε ξεχωριστό browsing context.

Η εσωτερική προσβασιμότητα και οι λειτουργίες αναπαραγωγής του εξαρτώνται από την εξωτερική υπηρεσία.
