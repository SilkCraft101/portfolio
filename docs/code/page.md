# `app/page.tsx`

## Ρόλος του αρχείου

Το αρχείο ορίζει την αρχική σελίδα του portfolio στη διαδρομή `/`.

## Components και σειρά εμφάνισης

Εισάγω τα `Hero`, `About`, `Projects` και `Hobbies` με named imports από τα αντίστοιχα αρχεία τους.

Το component `Home` επιστρέφει ένα `<main>` που τα εμφανίζει με αυτή τη σειρά. Εξάγεται με `export default`, όπως απαιτεί το Next.js για το page component.

Το `@/` στις εισαγωγές αντιστοιχεί στη ρίζα του project, σύμφωνα με το `tsconfig.json`.

## Σχέση με το layout

Το Navbar μεταφέρθηκε στο `app/layout.tsx` και αφαιρέθηκε από την αρχική, ώστε να εμφανίζεται μία φορά σε κάθε σελίδα.

Το περιεχόμενο του `Home` αποδίδεται στη θέση του `children`, μετά το κοινό Navbar. Τα `<html>`, `<body>` και ο Provider βρίσκονται ήδη στο root layout.

Το αρχείο παραμένει Server Component.

## Dynamic Rendering της αρχικής σελίδας

Η αρχική σελίδα χρησιμοποιεί τη ρύθμιση:

`export const dynamic = "force-dynamic";`

Η δήλωση βρίσκεται στο `app/page.tsx`, έξω από τη `function Home()`.

### Γιατί την πρόσθεσα

Το `components/about.tsx` υπολογίζει αυτόματα την ηλικία μου χρησιμοποιώντας την τρέχουσα ημερομηνία.

Αν η αρχική σελίδα δημιουργούνταν στατικά κατά το build, η ηλικία θα μπορούσε να παραμείνει αποθηκευμένη μέχρι το επόμενο deployment.

με το `force-dynamic`, το Next.js εκτελεί το rendering της αρχικής σελίδας σε κάθε νέο request.

Έτσι, η ηλικία υπολογίζεται εκ νέου χωρίς να απαιτείται ετήσια αλλαγή στον κώδικα ή νέο deployment.

### Συμπεριφορά και έλεγχοι

- Το Home παραμένει Server Component.
- Το Dynamic Rendering εφαρμόζεται στη διαδρομή /.
- Οι υπόλοιπες σελίδες διατηρούν τη δική τους συμπεριφορά rendering.
- Μια ήδη ανοιχτή σελίδα δεν ενημερώνεται αυτόματα χωρίς νέο request ή refresh.

Στο production build του Next.js 16.4.3 επιβεβαιώθηκε:

`ƒ /    (Dynamic) server-rendered on demand`

Η production έκδοση ελέγχθηκε τοπικά και εμφάνισε σωστά την ηλικία των 28 ετών στις 12 Νοεμβρίου 2026.

Η λογική υπολογισμού ηλικίας και η χρήση της ζώνης ώρας Europe/Athens τεκμηριώνονται στο [about.md](about.md).

## Τρέχον checkpoint

Η αρχική περιλαμβάνει τη συνοπτική παρουσίαση, τα Projects και τον αρχικό σκελετό των Ενδιαφερόντων.

Η `/about` λειτουργεί και το Works οδηγεί στην ενότητα Projects της αρχικής μέσω `/#works`. Το Hobbies παραμένει σε αναμονή.
