# `app/essays/philosophy/page.tsx`

## Σκοπός

Το αρχείο υλοποιεί τη σελίδα `/essays/philosophy`, η οποία
παρουσιάζει τα προσωπικά μου φιλοσοφικά δοκίμια.

Κάθε καρτέλα αντιπροσωπεύει ένα μεμονωμένο δοκίμιο,
χωρίς περιορισμό σε συγκεκριμένους φιλοσόφους ή υποκατηγορίες.

## Υλοποίηση

Το React component `PhilosophyPage()` περιλαμβάνει:

- `Container`: Περιορίζει το συνολικό πλάτος σε `6xl`.
- `Box`: Περιορίζει το πλάτος της εισαγωγής σε `3xl`.
- `Heading`: Εμφανίζει τον τίτλο της σελίδας.
- `Text`: Εμφανίζει τις εισαγωγικές παραγράφους.
- `Separator`: Διαχωρίζει την εισαγωγή από τα δοκίμια.
- `SimpleGrid`: Δημιουργεί responsive διάταξη:
  - Mobile: 1 στήλη.
  - Tablet: 2 στήλες.
  - Desktop: 3 στήλες.

## Design

- Georgia serif για τις εισαγωγικές παραγράφους.
- `fg.muted` για το δευτερεύον κείμενο.
- `border.subtle` για τα περιγράμματα.
- Responsive `fontSize`.

## Τρέχουσα κατάσταση - 18/12/2026

Η προσωρινή δοκιμαστική καρτέλα αφαιρέθηκε από τη σελίδα philosophy. Το `SimpleGrid` διατηρήθηκε, αλλά παραμένει κενό μέχρι να δημοσιεύσω κάποιο δοκίμιο.

Το προσωρινό αρχείο `content/essays/philosophy/test-essay.md` διαγράφηκε.

Η σελίδα `/essays/philosophy` διατηρεί την εισαγωγή και τη βασική της διάταξη.
