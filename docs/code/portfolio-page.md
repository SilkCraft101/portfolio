# `app/works/portfolio/page.tsx`

>

>
> Η παρούσα σελίδα λειτουργεί ως placeholder μέχρι να ολοκληρωθεί ο σχεδιασμός και η ανάπτυξη του Engineering Case Study.
>

## Ρόλος του αρχείου

Το αρχείο ορίζει τη σελίδα `/works/portfolio`, η οποία προορίζεται για την αναλυτική παρουσίαση του προσωπικού μου Portfolio.

Προς το παρόν εμφανίζει έναν τίτλο και ένα ενημερωτικό μήνυμα σχετικά με την κατάσταση ανάπτυξης.

Η διατήρηση της διαδρομής επιτρέπει την πλοήγηση από την αντίστοιχη κάρτα της σελίδας `/works`, χωρίς να απαιτείται η ολοκλήρωση του Engineering Case Study.

## Εισαγωγές και export

Από το Chakra UI χρησιμοποιούνται:

- `Box`
- `Container`
- `Heading`
- `Text`
- `Stack`

Η function `PortfolioPage` αποτελεί το default export της σελίδας.

Στο Next.js App Router, το αρχείο `page.tsx` ορίζει το περιεχόμενο της αντίστοιχης διαδρομής.

## Δομή της σελίδας

Το εξωτερικό `Box` αποδίδεται ως HTML `<main>`.

```tsx
<Box as="main">
```

Το `Container` περιορίζει το μέγιστο πλάτος του περιεχομένου:

```tsx
<Container maxW="3xl">
```

Το `Stack` οργανώνει κατακόρυφα τον τίτλο και το ενημερωτικό μήνυμα, χρησιμοποιώντας `gap={4}`.

## Περιεχόμενο

Η σελίδα περιλαμβάνει δύο βασικά στοιχεία.

### Τίτλος

```tsx
<Heading as="h1">Προσωπικό Portfolio</Heading>
```

Το `Heading` αποδίδεται ως `<h1>` και αποτελεί τον κύριο τίτλο της σελίδας.

### Ενημερωτικό μήνυμα

Το `Text` ενημερώνει τον επισκέπτη ότι η αναλυτική παρουσίαση του project βρίσκεται υπό μελέτη και ανάπτυξη.

Χρησιμοποιεί το semantic color token `fg.muted`, ώστε να ακολουθεί το υπάρχον σύστημα χρωμάτων του Portfolio.

## Τεχνική απόφαση

Η αρχική παρουσίαση του Portfolio αφαιρέθηκε επειδή πρόκειται να αντικατασταθεί από μια νέα προσέγγιση παρουσίασης των τεχνικών projects.

Αντί να διαγραφεί η διαδρομή `/works/portfolio`, διατηρήθηκε μια απλή λειτουργική σελίδα.

Με αυτόν τον τρόπο:

- Η κάρτα του Portfolio εξακολουθεί να οδηγεί σε υπαρκτή διαδρομή.
- Η πλοήγηση από το `/works` παραμένει λειτουργική.
- Η μελλοντική υλοποίηση μπορεί να πραγματοποιηθεί χωρίς να αλλάξει ο προορισμός του συνδέσμου.

## Μελλοντική ανάπτυξη

Η σελίδα προορίζεται να εξελιχθεί σε Engineering Case Study.

Ο σχεδιασμός προβλέπει παρουσίαση του σκοπού του project, της αρχιτεκτονικής, των τεχνικών αποφάσεων, των περιορισμών και των αποτελεσμάτων.

Η μελλοντική υλοποίηση ενδέχεται να χρησιμοποιήσει επαναχρησιμοποιήσιμη δομή για περισσότερα projects.

Οι παραπάνω δυνατότητες αποτελούν σχεδιασμό και δεν έχουν ακόμη υλοποιηθεί.
