# `app/works/[slug]/page.tsx`

## Ρόλος του αρχείου

Το αρχείο ορίζει την κοινή δυναμική σελίδα παρουσίασης όλων των τεχνικών έργων.

## Dynamic Routing

Το `[slug]` αποτελεί Τμήμα Δυναμικής Διαδρομής του Next.js App Router.
Η παράμετρος `slug` ανακτάται ασύγχρονα
μέσω του `await params`.

## Ανάκτηση δεδομένων

Ο πίνακας `projects` εισάγεται από το
`lib/projects.ts`.

Η μέθοδος `find()` αναζητά το project
του οποίου το slug αντιστοιχεί στο URL.

Αν δεν βρεθεί αντίστοιχο project,
η `notFound()` επιστρέφει σελίδα 404.

## Δομή και εμφάνιση

Η σελίδα χρησιμοποιεί τα Chakra UI components
`Box`, `Container` και `Stack.`

Το `Container` χρησιμοποιεί `maxW="5xl"`, ώστε να παρέχει περισσότερο χώρο για την παρουσίαση.

Η εισαγωγική ενότητα αποδίδεται μέσω του επαναχρησιμοποιήσιμου component `ProjectHero`, στο οποίο μεταβιβάζεται το αντικείμενο `project`.

Η λειτουργία του component τεκμηριώνεται στο [project-hero.md](project-hero.md).

## Τεχνική απόφαση

Η προηγούμενη στατική διαδρομή `app/works/portfolio/page.tsx` αντικαταστάθηκε από την κοινή δυναμική διαδρομή.

Η προσθήκη νέων projects δεν απαιτεί πλέον
τη δημιουργία ξεχωριστών σελίδων.
