# `components/project-hero.tsx`

## Ρόλος του αρχείου

Το `ProjectHero` αποτελεί την κοινή εισαγωγική ενότητα για την παρουσίαση όλων των έργων.

## Props

Το component δέχεται ένα αντικείμενο τύπου `Project` από το `lib/projects.ts`.

Εμφανίζει τον τίτλο, την περιγραφή, την εικόνα προεπισκόπησης και τους διαθέσιμους συνδέσμους.

## Responsive διάταξη

Το `SimpleGrid` δημιουργεί μία στήλη στο breakpoint `base` και δύο στήλες από το `md`.

Το `Stack` οργανώνει κατακόρυφα τα κείμενα, ενώ το `HStack` τοποθετεί οριζόντια τα κουμπιά.

## Σύνδεσμοι

Τα κουμπιά Live Demo και GitHub εμφανίζονται μέσω conditional rendering, εφόσον υπάρχουν οι αντίστοιχοι σύνδεσμοι στα δεδομένα του project.

Το Live Demo χρησιμοποιεί `variant="solid"`, ενώ το GitHub χρησιμοποιεί `variant="outline"`.

## Εικόνα προεπισκόπησης

Η εικόνα εμφανίζεται μέσω του `Image` του Next.js, με responsive πλάτος και διατήρηση των αναλογιών της.

Προς το παρόν χρησιμοποιείται η εικόνα `thumbnail`.

## Τεχνική απόφαση

Διαχωρίζω την εισαγωγική παρουσίαση από το `app/works/[slug]/page.tsx`, ώστε να αποτελεί ανεξάρτητο και επαναχρησιμοποιήσιμο component.
