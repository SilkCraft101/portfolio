# `lib/projects.ts`

## Ρόλος του αρχείου

Το αρχείο αποτελεί την κεντρική πηγή δεδομένων για τα τεχνικά projects.

## Δομή δεδομένων

Το TypeScript type `Project` καθορίζει τις ιδιότητες που πρέπει να διαθέτει κάτι έργο:

- `slug`: Μοναδικό αναγνωριστικό για τη διαδρομή.
- `title`: Τίτλος.
- `description`: Σύντομη περιγραφή.
- `thumbnail`: Εικόνα προεπισκόπησης.
- `technologies`: Τεχνολογίες.
- `status`: Κατάσταση ανάπτυξης.
- `links`: Προαιρετικοί σύνδεσμοι GitHub και Live Demo.

## Χρήση

Ο πίνακας `projects` χρησιμοποιείται από:

- `app/works/page.tsx`
- `app/works/[slug]/page.tsx`

Η προσθήκη ενός νέου έργου δεν απαιτεί τη δημιουργία ξεχωριστού `page.tsx`.

## Τεχνική απόφαση

Τα δεδομένα αποθηκεύονται τοπικά στο repo, ανεξάρτητα από το Vercel Blob, το οποίο χρησιμοποιείται αποκλειστικά για τα δοκίμια.

Η δομή θα επεκταθεί κατά την ανάπτυξη του Engineering Case Study Template.
