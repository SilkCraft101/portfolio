# Μαθησιακή τεκμηρίωση

Ο φάκελος αυτός περιλαμβάνει τις προσωπικές μου σημειώσεις από το Obsidian, τις οποίες δημιουργώ από την έναρξη αυτού του project.

Οι σημειώσεις ακολουθούν την προσέγγιση που ακολουθεί και το βιβλίο "CALCULUS For the Practical Man" με έμφαση στην πρακτική κατανόηση και εφαρμογή της γνώσης.

## Θεματικές ενότητες

- HTML
- CSS
- JavaScript
- TypeScript
- React
- Next.js
- Chakra UI
- Node.js
- Git και GitHub
- npm και ESLint
- Markdown και Obsidian
- Remark, Rehype και KaTeX
- Cloudinary και Vercel Blob
- Three.js, React Three Fiber και Drei
- Debugging και Testing
- Αρχιτεκτονική του Portfolio

## Συνεχής εξέλιξη σημειώσεων

Η συγγραφή και η ενημέρωση των σημειώσεων θα συνεχίζονται καθώς η ανάπτυξη του Portfolio δημιουργεί νέες μαθησιακές ανάγκες.

Κάθε νέα γνώση που απαιτείται για την κατανόηση και την υλοποίηση του project θα μελετάται, θα εφαρμόζεται και θα τεκμηριώνεται με τις αντίστοιχες πηγές.
