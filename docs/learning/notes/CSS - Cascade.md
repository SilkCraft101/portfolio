# Cascade

Το cascade αποφασίζει ποια δήλωση υπερισχύει, λαμβάνοντας υπόψη προέλευση, importance, layers, specificity και σειρά όπου χρειάζεται.

## Με απλά λόγια

Όταν δύο κανόνες λένε διαφορετικά πράγματα για το ίδιο στοιχείο, το cascade αποφασίζει ποιος θα ισχύσει.

## Χρήση

```css
/* Κανονικός κανόνας μέσα σε layer */
@layer base {
  p { color: brown; }
}

/* Κανονικός κανόνας εκτός layer */
p { color: black; }
```

Για αυτές τις κανονικές δηλώσεις ίδιας προέλευσης, ο κανόνας εκτός layer υπερισχύει. Το αποτέλεσμα δεν εξαρτάται μόνο από το ποια γραμμή γράφτηκε τελευταία.

Μετρούν η προέλευση, το importance, τα layers, η specificity και η σειρά, ανάλογα με τη σύγκριση. Για δηλώσεις `!important` της ίδιας προέλευσης και του ίδιου πλαισίου, τα layers έχουν αντίστροφη προτεραιότητα και υπερισχύουν των `!important` δηλώσεων εκτός layer.
