# Color Mix

Το color-mix() συνδυάζει χρώματα στον επιλεγμένο χρωματικό χώρο με αναλογίες.

## Με απλά λόγια

Φτιάχνω ένα ενδιάμεσο χρώμα αναμειγνύοντας δύο χρώματα με συγκεκριμένες αναλογίες.

## Χρήση

```css
.greeting {
  background: color-mix(in srgb, #F2B66D 10%, transparent);
}
```

Το `in srgb` επιλέγει χρωματικό χώρο. Το πρώτο χρώμα συμμετέχει με 10% και το υπόλοιπο είναι transparent. Η τιμή αυτή εφαρμόζεται μόνο στο background, όχι στο σύνολο των παιδιών.
