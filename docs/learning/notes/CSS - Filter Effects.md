# Filter Effects

Τα filter effects μεταβάλλουν οπτικά την απόδοση ενός στοιχείου. Το invert() αντιστρέφει τα χρώματα σε ορισμένο βαθμό.

## Με απλά λόγια

Το filter αλλάζει οπτικά το στοιχείο που έχει ήδη σχεδιαστεί, σαν να βάζω φίλτρο σε μια εικόνα.

## Χρήση

```css
.icon {
  filter: invert(1);
}
```

Το `invert(1)` αντιστρέφει πλήρως τα χρώματα του στοιχείου. Το `0` θα άφηνε τα χρώματα χωρίς αντιστροφή. Δεν αλλάζει την αρχική εικόνα που είναι αποθηκευμένη στο αρχείο.

Η αντιστροφή δεν είναι γενικός τρόπος δημιουργίας σωστής dark παλέτας. Για φόντο πίσω από στοιχείο υπάρχει η διαφορετική ιδιότητα backdrop-filter.
