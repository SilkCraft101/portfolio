# Fonts και Fallbacks

Το font-family δίνει μια σειρά προτιμώμενων γραμματοσειρών. Ο browser μπορεί να καταλήξει σε επόμενη επιλογή για χαρακτήρες που λείπουν.

## Με απλά λόγια

Δίνω μια σειρά γραμματοσειρών. Αν κάποια δεν είναι διαθέσιμη ή δεν έχει έναν χαρακτήρα, ο browser ψάχνει στην επόμενη.

## Χρήση

```css
body {
  font-family: var(--font-geist-sans), sans-serif;
}
```

Στο `app/layout.tsx` η Geist εκθέτει τη μεταβλητή που διαβάζει το `app/globals.css`. Όταν η τιμή της μεταβλητής υπάρχει, το `sans-serif` είναι η γενική εναλλακτική στη λίστα γραμματοσειρών. Αν λείπει η ίδια η μεταβλητή, αυτή η δήλωση γίνεται άκυρη. Για εκείνη την περίπτωση μπορώ να γράψω `var(--font-geist-sans, sans-serif)`. [CSS - Custom Properties](CSS%20-%20Custom%20Properties.md)

Η λίστα font-family στο Computed δεν αποδεικνύει ποια γραμματοσειρά σχεδίασε κάθε γράμμα. Ελέγχω και τα στοιχεία πραγματικής απόδοσης στον Inspector.
