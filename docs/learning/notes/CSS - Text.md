# Text

Οι ιδιότητες κειμένου ρυθμίζουν ζητήματα όπως αναδίπλωση και απόσταση γραμμάτων.

## Με απλά λόγια

Η εμφάνιση του κειμένου εξαρτάται και από τα κενά και τις αλλαγές γραμμής, όχι μόνο από τη γραμματοσειρά.

## Χρήση

```css
.title {
  letter-spacing: -0.02em;
  text-wrap: balance;
}
```

Το `letter-spacing` ρυθμίζει την απόσταση γραμμάτων. Το `text-wrap: balance` ζητά πιο ισορροπημένο μοίρασμα των γραμμών, κυρίως σε σύντομους τίτλους. Δεν εισάγει πραγματικά στοιχεία τίτλου ή νέες παραγράφους.
