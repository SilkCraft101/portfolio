# CLI

Το Chakra CLI μπορεί να προσθέτει UI snippets στο project, ώστε να υπάρχουν ως τοπικά αρχεία.

## Με απλά λόγια

Τα snippets είναι αρχεία κώδικα που προσθέτει το εργαλείο στο project. Μετά μπορώ να τα διαβάσω και να τα προσαρμόσω.

## Χρήση

```sh
npx @chakra-ui/cli snippet add
```

Το `snippet add` προσθέτει snippets μέσα στο project. Στο Portfolio υπάρχουν τα τοπικά `components/ui/provider.tsx` και `components/ui/color-mode.tsx`. Το tooltip παραμένει παράδειγμα διαθέσιμου snippet.

Δεν εκτελώ ξανά την εντολή αδιάκριτα πάνω σε δικές μου προσαρμογές. Ελέγχω πρώτα τις αλλαγές που πρόκειται να δημιουργήσει.
