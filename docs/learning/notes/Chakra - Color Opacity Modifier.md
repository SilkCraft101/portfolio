# Color Opacity Modifier

Η σύνταξη `χρώμα/ποσοστό` αναμειγνύει το χρώμα με διαφάνεια.

## Με απλά λόγια

Χρησιμοποιώ το ίδιο χρώμα με διαφορετικό βαθμό διαφάνειας. Έτσι μπορώ να έχω ήπιο φόντο χωρίς να ξεθωριάζω το κείμενο.

## Χρήση

```tsx
<Box bg="accent/10">
  <Text color="fg">Κείμενο</Text>
</Box>
```

Το `/10` αναμειγνύει 10% του χρώματος με 90% διαφανές χρώμα μέσω `color-mix()`. Για αδιαφανές token το αποτέλεσμα έχει alpha 10%. Επηρεάζει το background αυτού του Box, ενώ το κείμενο διατηρεί το δικό του χρώμα.

Με `opacity={0.1}` θα γινόταν πιο διάφανο ολόκληρο το Box μαζί με το περιεχόμενό του.
