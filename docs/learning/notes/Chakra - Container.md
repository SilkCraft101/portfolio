# Container

Το Container περιορίζει το πλάτος του περιεχομένου και παρέχει την προβλεπόμενη ευθυγράμμιση και εσωτερικά περιθώρια του Chakra.

## Με απλά λόγια

Το Container κρατά το κείμενο μέσα σε λογικά όρια, ώστε να μην απλώνεται σε όλη τη μεγάλη οθόνη.

## Χρήση

```tsx
<Container maxW="3xl">
  <Text>Το περιεχόμενο της σελίδας.</Text>
</Container>
```

Το `maxW` ορίζει μέγιστο πλάτος, όχι σταθερό πλάτος. Το `3xl` εδώ είναι size token. Το Container κρατά τις προεπιλεγμένες ρυθμίσεις του για κεντράρισμα και εσωτερικά περιθώρια, εφόσον δεν τις υπερκαλύπτει άλλο CSS.
