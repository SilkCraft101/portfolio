# Icon Button

Το IconButton είναι κουμπί του οποίου η ορατή πληροφορία είναι κυρίως ένα εικονίδιο.

## Με απλά λόγια

Ένα κουμπί με μόνο εικόνα χρειάζεται και ένα όνομα που να καταλαβαίνουν τα εργαλεία προσβασιμότητας.

## Χρήση

```tsx
<IconButton aria-label="Αλλαγή θέματος">
  <LuSun />
</IconButton>
```

Το `IconButton` είναι το κουμπί. Το `LuSun` δίνει το ορατό εικονίδιο. Το `aria-label` περιγράφει τη λειτουργία του για χρήστες που δεν βλέπουν το εικονίδιο. Δεν αρκεί να γράψω απλώς «ήλιος», όταν η ενέργεια είναι αλλαγή θέματος.
