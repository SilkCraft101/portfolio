# Link

Το Chakra Link παρέχει styles και συμπεριφορά συνδέσμου, με επιλογές για σύνθεση με άλλο στοιχείο.

## Με απλά λόγια

Το Chakra Link είναι ένας σύνδεσμος που δέχεται και τα styles του Chakra.

## Χρήση

```tsx
import { Link } from "@chakra-ui/react";

<Link href="https://github.com/SilkCraft101" color="accent">
  GitHub
</Link>
```

Το `href` είναι η διεύθυνση. Το `color` δέχεται token. Αν χρησιμοποιώ και το Link του Next.js, μπορώ να γράψω `Link as ChakraLink` στο import για να ξεχωρίζουν τα ονόματά τους.
