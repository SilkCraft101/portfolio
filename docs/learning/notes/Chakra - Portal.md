# Portal

Το Portal αποδίδει περιεχόμενο σε διαφορετική θέση του DOM από τη θέση του μέσα στο component tree.

## Με απλά λόγια

Το Portal εμφανίζει κάτι σε άλλο σημείο του HTML, ενώ παραμένει παιδί του ίδιου React component tree.

## Χρήση

```tsx
<Portal>
  <div>Περιεχόμενο πάνω από την υπόλοιπη σελίδα</div>
</Portal>
```

Στον browser το περιεχόμενο αποδίδεται από προεπιλογή στο τέλος του `body`. Κατά την απόδοση στον server, το Chakra αποδίδει το περιεχόμενο στην αρχική του θέση. Έτσι overlays μπορούν να αποφύγουν περιορισμούς του αρχικού τους περιβλήματος. Η React σχέση γονέα και παιδιού, όπως το context, διατηρείται.
