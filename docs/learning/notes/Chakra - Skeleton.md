# Skeleton

Το Skeleton είναι προσωρινή οπτική θέση για περιεχόμενο που δεν είναι ακόμη έτοιμο.

## Με απλά λόγια

Το Skeleton κρατά μια προσωρινή θέση όσο το πραγματικό περιεχόμενο δεν είναι ακόμη έτοιμο.

## Χρήση

```tsx
<Skeleton boxSize="9" />
```

Το `boxSize` δίνει ίδιο πλάτος και ύψος από τα size tokens. Έτσι κρατάω χώρο για ένα μικρό στοιχείο, όπως ένα κουμπί, και η διάταξη δεν αλλάζει απότομα όταν εμφανιστεί.
