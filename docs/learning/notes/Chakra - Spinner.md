# Spinner

Το Spinner είναι οπτική ένδειξη ότι μια διαδικασία βρίσκεται σε εξέλιξη.

## Με απλά λόγια

Το Spinner δείχνει ότι μια εργασία συνεχίζεται. Δεν δείχνει πόσο ποσοστό έχει ολοκληρωθεί.

## Χρήση

```tsx
<Spinner size="sm" color="accent" />
```

Το `size` ορίζει μέγεθος και το `color` χρώμα. Η εφαρμογή εμφανίζει το Spinner όσο διαρκεί η φόρτωση. Όταν αποτελεί τη μοναδική ένδειξη, προσθέτω κείμενο κατάστασης για τις υποστηρικτικές τεχνολογίες.
