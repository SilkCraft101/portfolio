# Typography Tokens

Τα typography tokens συγκεντρώνουν γραμματοσειρές, μεγέθη, βάρη, αποστάσεις γραμμάτων και ύψη γραμμής.

## Με απλά λόγια

Δίνω γνωστά ονόματα σε μεγέθη και αποστάσεις γραμμάτων, ώστε το κείμενο να έχει συνοχή.

## Χρήση

```tsx
<Text fontSize="sm" fontWeight="medium" lineHeight="tall">
  Σύντομη περιγραφή
</Text>
```

Τα `sm`, `medium` και `tall` είναι τιμές από διαφορετικά σύνολα typography tokens. Δεν περιγράφουν όλα το μέγεθος: το ένα αφορά font size, το άλλο βάρος και το άλλο ύψος γραμμής.
