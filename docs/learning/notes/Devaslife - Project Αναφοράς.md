# Project Αναφοράς

Το craftzdog-homepage του devaslife είναι σχεδιαστική και tutorial αναφορά για το portfolio.

## Με απλά λόγια

Μια σχεδιαστική αναφορά με βοηθά να σκεφτώ τη μορφή του site. Για το πώς λειτουργεί κάθε API κοιτάζω την τεχνική τεκμηρίωση.

Το craftzdog-homepage του Takuya Matsuyama / devaslife είναι αναφορά για στοιχεία όπως το greeting, η παρουσίαση με εικόνα προφίλ και η οργάνωση των ενοτήτων. Το περιεχόμενο και η παλέτα του δικού μου site προσαρμόζονται στη δική μου χρήση. Το έργο αναφοράς χρησιμοποιεί άδεια MIT. Το README του δημιουργού ζητά σύνδεσμο προς την αρχική του σελίδα και αποκλείει τη χρήση του δικού του 3D voxel σκύλου στις παράγωγες αρχικές σελίδες.
