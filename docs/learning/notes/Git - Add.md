# Add

Το git add προετοιμάζει συγκεκριμένο περιεχόμενο για το επόμενο commit τοποθετώντας το στο index.

## Με απλά λόγια

Το add επιλέγει ποια τωρινή εκδοχή του περιεχομένου θέλω να μπει στο επόμενο commit.

## Χρήση

```sh
git add components/hero.tsx
git status
```

Η πρώτη γραμμή βάζει το αρχείο στο staging area. Η δεύτερη επιβεβαιώνει το αποτέλεσμα. Το `git add .` αφορά τις αλλαγές κάτω από τον τρέχοντα φάκελο.

Αν αλλάξω το αρχείο μετά το add, η νέα αλλαγή δεν έχει προστεθεί ακόμη στο staging area. Το add χωρίς διαδρομή δεν επιλέγει κάτι αυτόματα.
