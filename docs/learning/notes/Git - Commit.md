# Commit

Το commit καταγράφει στο τοπικό ιστορικό ένα στιγμιότυπο του περιεχομένου που έχει προετοιμαστεί στο staging area.

## Με απλά λόγια

Το commit κρατά ένα στιγμιότυπο όσων έχω επιλέξει. Με το push μπορώ να στείλω το commit και στο απομακρυσμένο repository.

## Χρήση

```sh
git commit --message="Ενημέρωση παρουσίασης Hero"
```

Το `--message` δίνει την περιγραφή. Τα εισαγωγικά κρατούν ολόκληρο το κείμενο ως μία τιμή. Στο commit μπαίνουν οι staged αλλαγές, όχι αυτομάτως κάθε τροποποιημένο αρχείο.

Το μήνυμα περιγράφει τη συγκεκριμένη ολοκληρωμένη αλλαγή. Το commit δεν είναι push.
