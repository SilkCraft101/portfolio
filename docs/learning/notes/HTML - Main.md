# Main

Το main δηλώνει το κυρίαρχο περιεχόμενο του εγγράφου.

## Με απλά λόγια

Το main ξεχωρίζει το κύριο περιεχόμενο της συγκεκριμένης σελίδας από την κοινή πλοήγηση.

## Χρήση

```html
<nav>Κοινή πλοήγηση</nav>
<main>
  <h1>Σχετικά με εμένα</h1>
  <p>Το περιεχόμενο της σελίδας.</p>
</main>
```

Το nav αφορά την πλοήγηση. Το main αφορά τον βασικό σκοπό της σελίδας. Σε ένα έγγραφο επιτρέπεται μόνο ένα `main` χωρίς το attribute `hidden`. Με Chakra μπορώ να αποδώσω main με `<Box as="main">`.
