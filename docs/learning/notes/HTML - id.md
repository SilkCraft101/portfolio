# id

Το id δίνει μοναδικό αναγνωριστικό σε ένα στοιχείο HTML. Μπορεί να γίνει προορισμός ενός fragment link.

## Με απλά λόγια

Το id είναι ένα μοναδικό όνομα για να μπορώ να αναγνωρίζω ένα συγκεκριμένο στοιχείο.

## Χρήση

```html
<section id="works">
  <h2>Projects</h2>
</section>
```

Το `id="works"` δίνει όνομα στην ενότητα. Ένας σύνδεσμος με `href="#works"` μπορεί να οδηγήσει εκεί. Η τιμή δεν περιέχει κενά και δεν επαναλαμβάνεται στην ίδια σελίδα.

## Πηγή

- [Τεκμηρίωση](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/id)
