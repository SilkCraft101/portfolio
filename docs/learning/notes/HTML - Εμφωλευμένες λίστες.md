# Εμφωλευμένες λίστες

Το ul οργανώνει μη αριθμημένα στοιχεία li. Μια δεύτερη λίστα μέσα σε li αποδίδει υποεπίπεδο.

## Με απλά λόγια

Μια λίστα μπορεί να έχει μικρότερη λίστα μέσα της. Έτσι δείχνω ότι κάποια στοιχεία ανήκουν σε ένα μεγαλύτερο θέμα.

## Χρήση

```html
<ul>
  <li>
    Κεφάλαιο 1
    <ul>
      <li>Κεφάλαιο 1.1</li>
      <li>Κεφάλαιο 1.2</li>
    </ul>
  </li>
  <li>Κεφάλαιο 2</li>
</ul>
```

Το `ul` είναι η λίστα και κάθε `li` ένα στοιχείο της. Η δεύτερη `ul` βρίσκεται μέσα στο πρώτο `li`, πριν από το κλείσιμό του. Δεν βάζω ένα `li` απευθείας μέσα σε άλλο `li`.
