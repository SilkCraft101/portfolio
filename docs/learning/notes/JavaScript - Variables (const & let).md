# Τι είναι οι μεταβλητές

Οι μεταβλητές χρησιμοποιούνται για να αποθηκεύουμε τιμές τις οποίες θέλουμε να χρησιμοποιήσουμε στον κώδικα μας.

Στην JavaScript μπορούμε να δηλώσουμε μεταβλητές χρησιμοποιώντας `const` ή `let`.

## Με απλά λόγια

Μια μεταβλητή είναι όνομα που χρησιμοποιούμε για να αναφερόμαστε σε μια τιμή.
Για παράδειγμα, αντί να γράφουμε συνεχώς το έτος γέννησης μας, μπορούμε να το αποθηκεύσουμε σε μια μεταβλητή με όνομα `birthYear`.

Έτσι, όταν χρειαζόμαστε αυτή την πληροφορία, χρησιμοποιούμε το όνομα της μεταβλητής. 

## Δήλωση μεταβλητών

### `const`

Χρησιμοποιούμε `const` όταν δεν σκοπεύουμε να αναθέσουμε διαφορετική τιμή στη μεταβλητή.

```js
const birthYear = 1997;

console.log(birthYear);
```

**Τι συμβαίνει εδώ;**
- `const`: Δηλώνει μια μεταβλητή στην οποία δεν επιτρέπεται επαν-ανάθεση.
- `birthYear`: Είναι το όνομα της μεταβλητής.
- `=`: Είναι ο τελεστής ανάθεσης.
- 1997: είναι η τιμή που αναθέτουμε.
- `console.log(birthYear)`: Εμφανίζει την τιμή 1997 στην κονσόλα.

Αν προσπαθήσουμε να αναθέσουμε διαφορετική τιμή:

```js
const birthYear = 1997;

birthYear = 2000;
```

Η JavaScript θα εμφανίσει `TypeError`, επειδή δεν επιτρέπεται η επαν-ανάθεση σε μεταβλητή που δηλώθηκε με `const`.

> [!WARNING]
> **Προσοχή**
>
> Το `const` δεν σημαίνει ότι κάθε τιμή γίνεται απολύτως αμετάβλητη.
> Στα `objects` και `arrays` μπορούν να τροποποιηθούν τα περιεχόμενα τους.
> Αυτό θα το μελετήσω αργότερα.

### `let`

Χρησιμοποιούμε `let` όταν η μεταβλητή ενδέχεται να χρειαστεί διαφορετική τιμή κατά την εκτέλεση του προγράμματος.

```js
let currentYear = 2026;

console.log(currentYear);

currentYear = 2027;

console.log(currentYear);
```

**Τι συμβαίνει εδώ;**
1. Δηλώνουμε τη μεταβλητή `currentYear` με τιμή 2026.
2. Εμφανίζουμε την αρχική τιμή.
3. Αναθέτουμε νέα τιμή (2027) στην ίδια μεταβλητή.
4. Εμφανίζουμε την ενημερωμένη τιμή.

Δεν χρειάζεται να γράψουμε ξανά `let` για να αλλάξουμε την τιμή.

## Δήλωση και ανάθεση

Η **δήλωση (declaration)** δημιουργεί τη μεταβλητή.

Η **ανάθεση (assignment)** της δίνει μια τιμή.

Με το `let`, μπορούμε να κάνουμε αυτά τα δύο σε διαφορετικές γραμμές:

```js
let age;
age = 28;

console.log(age);
```

Αντίθετα, μια συνηθισμένη δήλωση `const` απαιτεί αρχική τιμή:

```js
const age = 28;
```

## Πότε χρησιμοποιώ `const` και πότε `let`;

Ο γενικός κανόνας που θέλω να ακολουθώ είναι:

- `const` όταν δεν χρειάζεται επαναανάθεση.
    
- `let` όταν χρειάζεται να αναθέσω διαφορετική τιμή αργότερα.
    

Δεν χρειάζεται να χρησιμοποιώ `let` απλώς επειδή η τιμή αναφέρεται σε κάτι που αλλάζει στον πραγματικό κόσμο.

Για παράδειγμα, το `currentYear` μπορεί να δηλωθεί με `const` αν ο κώδικας υπολογίζει το έτος κάθε φορά που εκτελείται και δεν επαναναθέτει τη μεταβλητή.

## Σύνδεση με το portfolio

Κρατάω τον υπολογισμό ηλικίας ως άσκηση μεταβλητών. Στο Portfolio το `components/about.tsx` χρησιμοποιεί `let age`, επειδή μπορεί να αφαιρεθεί ένα έτος.

Για να το πετύχω αυτό, θα χρειαστώ μεταβλητές που αντιπροσωπεύουν:
- Το έτος γέννησης μου.
- Το τρέχον έτος.
- Την υπολογισμένη ηλικία.

Ένα απλό παράδειγμα είναι:

```js
const birthYear = 1997;
const currentYear = 2026;

const age = currentYear - birthYear;

console.log(age);
```

Το αποτέλεσμα είναι 29.

> [!IMPORTANT]
> **Σημαντικό**
>
> Αυτό δεν υπολογίζει την ακριβή ηλικία μου. Επειδή έχω γεννηθεί 18 Δεκεμβρίου, πριν από τα γενέθλιά μου το 2026 είμαι ακόμη 28 ετών.

Για ακριβή υπολογισμό στην άσκηση θα χρειαστεί να εξετάσουμε και τον μήνα και την ημέρα, χρησιμοποιώντας το `JavaScript Date`. Προς το παρόν, το παράδειγμα χρησιμεύει μόνο για την κατανόηση των μεταβλητών.

## Συνηθισμένα λάθη

### 1. Προσπάθεια επαν-ανάθεσης σε `const`

```js
const age = 28;

age = 29;
```

Αυτό προκαλεί σφάλμα.

### 2. Σύγχυση μεταξύ `=` και `===`

Το `=` χρησιμοποιείται για ανάθεση τιμής.

Το `===` χρησιμοποιείται για σύγκριση αυστηρής ισότητας. Θα το εξετάσω αναλυτικότερα όταν μελετήσω τις συνθήκες.

### 3. Τιμή μετά από δήλωση `let age;`

```js
let age;

console.log(age);
```

Μετά τη δήλωση, το αποτέλεσμα είναι `undefined`. Πρόσβαση πριν εκτελεστεί η δήλωση προκαλεί `ReferenceError`.

### 4. Σύγχυση δήλωσης και επαν-ανάθεσης

```js
let age = 28;

age = 29;
```

Η δεύτερη γραμμή δεν δημιουργεί νέα μεταβλητή. Αλλάζει την τιμή της ήδη υπάρχουσας.
