# Ένα παράθεμα μέσα στο Markdown

Το `>` ξεκινά παράθεμα. Για δύο παραγράφους βάζω μια γραμμή με σκέτο `>` ανάμεσά τους.

```markdown
> Η πρώτη σκέψη.
>
> Η δεύτερη σκέψη.

Η αφήγηση συνεχίζεται εδώ.
```

Η κενή γραμμή χωρίς `>` χωρίζει την επόμενη παράγραφο από το παράθεμα. Αν την παραλείψω, το CommonMark μπορεί να διαβάσει τη συνέχεια ως μέρος του ίδιου παραθέματος. Με δεύτερο `>` μπορώ να γράψω παράθεμα μέσα σε παράθεμα.

Στα Essays το απλό παράθεμα αποδίδεται ως `blockquote` και μορφοποιείται στο `app/globals.css`. Ένα `> [!warning]` προσθέτει ειδική σήμανση που επεξεργάζεται το [Rehype - Callouts](Rehype%20-%20Callouts.md).

- [CommonMark — Block quotes, παραδείγματα 244, 247 και 248](https://spec.commonmark.org/0.31.2/#block-quotes)
