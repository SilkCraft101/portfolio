# Create Next App

Το create-next-app δημιουργεί την αρχική δομή ενός Next.js project με επιλεγμένες ρυθμίσεις.

## Με απλά λόγια

Το create-next-app ετοιμάζει τον αρχικό σκελετό. Μετά αλλάζω αυτόν τον σκελετό για τη δική μου εφαρμογή.

## Χρήση

```sh
npx create-next-app@latest my-portfolio
```

Το `npx` εκτελεί το εργαλείο. Το `my-portfolio` είναι το όνομα του νέου project. Το εργαλείο ζητά επιλογές για τη ρύθμιση.

Είναι παράδειγμα δημιουργίας νέου project. Δεν το ξανατρέχω μέσα στο υπάρχον portfolio για να προσθέσω σελίδα. Το scaffold μπορεί να περιλαμβάνει αρχεία που αργότερα δεν χρησιμοποιούνται.
