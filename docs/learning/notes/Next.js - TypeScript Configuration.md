# TypeScript Configuration

Το Next.js ενσωματώνει TypeScript υποστήριξη και παράγει δηλώσεις τύπων για το περιβάλλον του.

## Με απλά λόγια

Το Next.js δημιουργεί και χρειάζεται κάποια αρχεία τύπων για να καταλαβαίνει η TypeScript το περιβάλλον του.

## Χρήση

```ts
// Παράδειγμα αναφοράς μέσα στο παραγόμενο next-env.d.ts:
/// <reference types="next" />
```

Η αναφορά κάνει διαθέσιμες τις δηλώσεις τύπων του Next.js. Το πραγματικό παραγόμενο αρχείο μπορεί να περιέχει και άλλες αναφορές, ανά έκδοση και ρύθμιση.

Δεν γράφω δικό μου κώδικα στο next-env.d.ts, γιατί αναδημιουργείται. Για δικούς μου τύπους χρησιμοποιώ δικό μου αρχείο.
