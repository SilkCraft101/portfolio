Τα **Callouts** είναι ειδικά μορφοποιημένα Markdown Blockquotes που χρησιμοποιούνται για την επισήμανση πληροφοριών, προειδοποιήσεων, παραδειγμάτων, παραθεμάτων και προσωπικών σκέψεων.

## Με απλά λόγια

Ένα συνηθισμένο Blockquote χρησιμοποιεί το σύμβολο `>`.

Το Obsidian επεκτείνει αυτή τη σύνταξη με το `[!type]`, ώστε να αναγνωρίζει διαφορετικούς τύπους περιεχομένου.

Για παράδειγμα:

```
> [!warning]
> Προσοχή σε αυτό το σημείο.
```

Το Obsidian εμφανίζει ένα πλαίσιο προειδοποίησης με συγκεκριμένο χρώμα και εικονίδιο.

## Χρήση

Η γενική σύνταξη είναι:

```
> [!type] Προαιρετικός τίτλος
> Περιεχόμενο του Callout.
```

- `>`: Δηλώνει Markdown Blockquote.
    
- `[!type]`: Καθορίζει τον τύπο του Callout.
    
- `Προαιρετικός τίτλος`: Αντικαθιστά τον προεπιλεγμένο τίτλο.
    
- `Περιεχόμενο`: Μπορεί να περιλαμβάνει κανονικό Markdown.
    

### Διαθέσιμοι τύποι

Το Obsidian διαθέτει 13 βασικούς τύπους:

|Τύπος|Εναλλακτικά ονόματα|
|---|---|
|`note`|—|
|`abstract`|`summary`, `tldr`|
|`info`|—|
|`todo`|—|
|`tip`|`hint`, `important`|
|`success`|`check`, `done`|
|`question`|`help`, `faq`|
|`warning`|`caution`, `attention`|
|`failure`|`fail`, `missing`|
|`danger`|`error`|
|`bug`|—|
|`example`|—|
|`quote`|`cite`|

Τα αναγνωριστικά δεν κάνουν διάκριση πεζών και κεφαλαίων (_case-insensitive_).

Οι μη αναγνωρισμένοι τύποι εμφανίζονται με την προεπιλεγμένη μορφοποίηση `note`, εκτός αν έχουν οριστεί διαφορετικά.

### Αναδιπλούμενα Callouts

Προσθέτουμε `+` ή `-` αμέσως μετά το `[!type]`.

```
> [!note]+ Αρχικά ανοιχτό
> Το περιεχόμενο εμφανίζεται.

> [!note]- Αρχικά κλειστό
> Το περιεχόμενο είναι κρυφό.
```

Και οι δύο μορφές επιτρέπουν άνοιγμα και κλείσιμο από τον χρήστη.

### Εμφωλευμένα Callouts

Ένα Callout μπορεί να περιέχει άλλο Callout (_nesting_).

```
> [!question] Τι γνωρίζω;
> > [!note] Προσωπική παρατήρηση
> > Χρειάζομαι περισσότερη μελέτη.
```

Κάθε επίπεδο προσθέτει ένα επιπλέον `>`.

### Προσαρμογή εμφάνισης

Το Obsidian επιτρέπει την προσαρμογή των Callouts μέσω CSS snippets.

Παράδειγμα:

```
.callout[data-callout="custom"] {
  --callout-color: 100, 150, 200;
  --callout-icon: lucide-book;
}
```

- `data-callout`: Αναγνωρίζει τον τύπο.
- `--callout-color`: Καθορίζει το χρώμα.
- `--callout-icon`: Καθορίζει το εικονίδιο.

Αυτές οι συμβάσεις αφορούν το Obsidian και δεν εφαρμόζονται αυτόματα σε άλλες εφαρμογές.

## Πρακτικό παράδειγμα

Θέλουμε να ξεχωρίσουμε έναν εσωτερικό διάλογο από την υπόλοιπη αφήγηση ενός δοκιμίου.

```
Ερωτώ τον εαυτό μου:

> [!quote] Εσωτερικός διάλογος
> "Ποιο είναι το σημαντικότερο πράγμα που έκανα σήμερα;"

Η απάντηση δεν βρίσκεται απαραίτητα σε όσα ολοκλήρωσα.

> [!important] Κεντρική ιδέα
> Η πραγματική πρόοδος απαιτεί κατανόηση.
```

**Ανάλυση:**

Το `[!quote]` παρουσιάζει την προσωπική ερώτηση ως ξεχωριστό λογοτεχνικό απόσπασμα.

Στο Portfolio το `[!important]` παίρνει το χρώμα έμφασης που ορίζουν οι κανόνες για τον συγκεκριμένο τύπο.

Το υπόλοιπο Markdown παραμένει ανεπηρέαστο.

## Συνηθισμένα λάθη

**Σύγχυση Blockquote και Callout:**

```
> Ένα απλό Blockquote.
```

Δεν είναι ισοδύναμο με:

```
> [!quote]
> Ένα Callout τύπου quote.
```

**Παράλειψη του `>` από το περιεχόμενο:**

```
> [!note]
Η συνέχεια μπορεί να παραμείνει μέσα στο blockquote.
```

Στο CommonMark, μια γραμμή που συνεχίζει την ίδια παράγραφο μπορεί να παραμείνει μέσα στο blockquote ακόμη και χωρίς `>`. Χρησιμοποιώ `>` σε κάθε γραμμή που ανήκει στο Callout και αφήνω κενή γραμμή πριν συνεχίσω έξω από αυτό.

**Υπόθεση ότι όλοι οι Markdown renderers υποστηρίζουν Callouts:**

Η σύνταξη `[!type]` είναι επέκταση του Obsidian και δεν αποτελεί μέρος του βασικού CommonMark.
