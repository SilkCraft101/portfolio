# Πώς συνδέονται τα μέρη της gallery

## Το συγκεκριμένο πρόβλημα

Θέλω να ανεβάζω ζωγραφιές σε έναν φάκελο και να εμφανίζονται στο site, με πλέγμα και μεγέθυνση. Δεν υπάρχει ένα μόνο API που να κάνει όλα αυτά.

## Η σειρά

1. Ανεβάζω εικόνες στη Media Library του Cloudinary, στον φάκελο `portfolio/paintings`.
2. Το Next.js φορτώνει τις ρυθμίσεις και το SDK συνδέεται από τον server.
3. Το Search API ζητά τις εγγραφές εικόνων. Το await περιμένει την απάντηση.
4. Η επανάληψη με cursor συγκεντρώνει τυχόν επιπλέον παρτίδες.
5. Η map δημιουργεί μία καταχώρηση για κάθε ζωγραφιά.
6. Το SimpleGrid τις τοποθετεί σε στήλες. Το Image εμφανίζει κάθε εικόνα.
7. Το Dialog ανοίγει τη μεγαλύτερη προβολή όταν πατάω τη μικρογραφία.
8. Το ISR επιτρέπει να ξαναδημιουργηθεί η δημοσιευμένη σελίδα με νεότερη λίστα.

## Γιατί φαίνεται διαφορετικό από τις πηγές;

Οι πηγές εξηγούν κάθε εργαλείο χωριστά. Το πρόβλημα του portfolio απαιτεί τον συνδυασμό τους. Δεν χρειάζεται να αντιγράψω τη βάση δεδομένων ενός παραδείγματος, το blog ενός άλλου και το κουμπί ενός τρίτου.

Για κάθε παράδειγμα ξεχωρίζω: ποιο μέρος είναι το API που χρειάζομαι, ποιο είναι απλώς ενδεικτικά δεδομένα και ποιο είναι δική μας επιλογή διάταξης. Αν εμφανίζεται νέα σύνταξη, τη μελετώ χωριστά πριν τη χρησιμοποιήσω σε δικό μου παράδειγμα.

## Με απλά λόγια

Πρώτα βρίσκω τις ζωγραφιές. Μετά φτιάχνω τις καταχωρήσεις. Μετά ορίζω διάταξη και αλληλεπίδραση. Τα διαφορετικά παραδείγματα συνδέονται σε αυτά τα συγκεκριμένα βήματα.

Οι ακριβείς πηγές και τα σχετικά τμήματα βρίσκονται στις επιμέρους σημειώσεις. Αυτή είναι εξήγηση της ροής, όχι ισχυρισμός ότι έχω ήδη κατακτήσει όλα τα μέρη της.
