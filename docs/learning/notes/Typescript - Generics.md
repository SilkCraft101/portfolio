# Generics

Ένα generic επιτρέπει σε μια δήλωση να δουλεύει με διαφορετικούς τύπους, διατηρώντας τη σχέση ανάμεσα στις εισόδους και στο αποτέλεσμα.

## Με απλά λόγια

Δεν χρειάζεται να αποφασίσω έναν μοναδικό τύπο για κάθε χρήση. Το generic κρατά τη σχέση του τύπου εισόδου με τον τύπο εξόδου.

## Χρήση

```ts
function identity<T>(value: T): T {
  return value;
}

const answer = identity(42);
const message = identity("Καλημέρα");
```

Το `T` είναι παράμετρος τύπου. Η πρώτη κλήση διατηρεί τη σχέση με την τιμή `42` και η δεύτερη με τη συμβολοσειρά `"Καλημέρα"`. Μπορώ επίσης να ορίσω ρητά `identity<number>(42)`. Η συνάρτηση επιστρέφει τον ίδιο τύπο που δέχεται. Το `T` δεν είναι μεταβλητή δεδομένων κατά την εκτέλεση.
