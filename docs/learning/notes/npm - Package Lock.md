# Package Lock

Το package-lock.json καταγράφει το επιλυμένο dependency tree, ώστε οι εγκαταστάσεις να είναι αναπαραγώγιμες.

## Με απλά λόγια

Το package.json λέει τι εκδόσεις επιτρέπω. Το lockfile κρατά τις συγκεκριμένες εκδόσεις και τις σχέσεις που επιλύθηκαν στην εγκατάσταση.

## Χρήση

```sh
npm install
```

Η εγκατάσταση χρησιμοποιεί τα manifests και, ανάλογα με την κατάστασή τους, μπορεί να ενημερώσει το package-lock.json. Μετά από αλλαγή dependencies ελέγχω και τα δύο αρχεία.

Δεν επεξεργάζομαι χειροκίνητα το lockfile για να προσθέσω βιβλιοθήκη. Περιλαμβάνει και μεταβατικές εξαρτήσεις, δηλαδή βιβλιοθήκες που χρειάζονται άλλες βιβλιοθήκες.
